# Trial Rider GP — R1 edition

A physics moto-trials game built for the Rabbit R1's 240x282 screen. Position-based two-wheel physics at 240 Hz, analog throttle, air control, checkpoints and a finish timer.

Play: open index.html or the GitHub Pages site. Controls: GAS/BRAKE/LEAN touch buttons, arrow keys / WASD on desktop, scroll wheel leans on the R1.
